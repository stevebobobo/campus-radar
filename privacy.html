隱私權政策

校園輿情雷達（Campus Radar）・最後更新：2026-11-15

這個工具在做什麼

校園輿情雷達協助學校了解公開網路上與學校有關的討論，例如校園設施、宿舍、課程的意見與突發事件，讓學校能及早回應學生的需求。

我們讀取哪些資料

  • 只讀取公開內容：Dcard、PTT、Threads、Instagram、YouTube、Google 地圖、Google 新聞與 Google 快訊上，以學校名稱、學校主題標籤或 hashtag 搜尋得到的貼文、影片與評論。
  • 透過各平台的官方 API 或公開頁面讀取，不登入他人帳號，不讀取私人訊息、私人帳號或非公開社團。
  • Threads 資料經由 Meta 官方 Threads API 的關鍵字搜尋功能取得。
  • Instagram 資料經由 Meta 官方 Instagram API 的 hashtag 搜尋功能取得；Google 地圖評論經由 Google Places API 取得。

我們保存哪些資料

  • 保存：貼文的文字內容、發文時間、公開連結、平台名稱、互動數（讚、留言數）。
  • 不保存：發文者的帳號名稱、個人頁、大頭貼、學校科系、性別或任何可識別個人的資料。
  • 資料存放在有密碼保護的系統中，只有學校授權的承辦人員可以查看，不公開、不出售、不提供給第三方，也不用於廣告。
  • 學校相關的貼文保存 120 天，其他學校的比較資料保存 30 天，期滿自動刪除。

資料用途

僅用於學校內部了解校園輿情、改善校務與即時處理突發事件，不用於追查、懲處或聯繫個別發文者。

刪除資料

如果您的公開貼文被本工具收錄，而您希望刪除，請寄信到下方聯絡信箱，並附上貼文連結。我們會在 7 個工作天內從系統中刪除該筆資料並回覆您。您在原平台刪除貼文後，本工具也不會再讀取到該貼文。
